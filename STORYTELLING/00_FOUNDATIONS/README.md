# 00 — Foundations: What Is a Story?

Before any modern storytelling book, there was one question asked ~2,350 years ago: *why do some
stories feel whole and satisfying while others feel like a random pile of events?* Aristotle wrote
the first surviving answer. Almost every framework you'll meet later — the three-act structure, the
inciting incident, the twist, the emotional payoff — is a descendant of the vocabulary he invented.
Start here so the rest of the course has roots.

## 🎯 Goal of this chapter

Walk away with a precise definition of "story" (not just "stuff that happens") and the oldest,
sturdiest toolkit for judging whether a story is built right: does it have unity, a real turn, and
an earned emotional release?
