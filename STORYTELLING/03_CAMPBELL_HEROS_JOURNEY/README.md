# 03 — The Hero with a Thousand Faces: Joseph Campbell

Aristotle told you what a *plot* is. Campbell noticed something bigger and stranger: that myths from
completely disconnected cultures — Greek, Buddhist, Aztec, Aboriginal — keep telling the *same story*
with different costumes. He called that shared skeleton the **monomyth**, or the Hero's Journey. It's
the most influential single idea in modern storytelling: *Star Wars*, *The Lion King*, *The Matrix*,
and a thousand others are built on it, often on purpose.

## 🎯 Goal of this chapter

See the universal skeleton under most stories that move us, understand *why* it recurs (it's a map of
psychological transformation, not just a plot template), and be able to use it — and know when *not*
to, so your work doesn't feel like a paint-by-numbers myth.
