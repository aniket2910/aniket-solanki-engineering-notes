# 🖼️ 08 · Multimodal AI

Modern models handle more than text: they can **see images, hear audio, and speak**. Multimodal features unlock things like "describe this screenshot," voice interfaces, and image generation. Pull this chapter in when a project actually needs it.

## 🎯 Goal of this chapter

Send an image to a vision model and get a description back, and transcribe an audio clip to text — the two most common multimodal building blocks.
