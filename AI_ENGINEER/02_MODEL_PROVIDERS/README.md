# 🏭 02 · Model Providers

Where the models actually come from, how to call each one, and how to choose. You'll learn the trade-off between **closed hosted models** (best quality, pay per token) and **open models** (free, private, run them yourself).

## 🎯 Goal of this chapter

Call at least two providers with the same code shape, run one model locally for free, and have a rule of thumb for **which model to reach for** on a given task.
