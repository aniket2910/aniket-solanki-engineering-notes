# 🧲 04 · Embeddings

Embeddings turn text (or images, audio) into **lists of numbers** that capture *meaning*. Two texts about similar things end up as nearby number-lists. This is the foundation of semantic search, RAG, recommendations, and clustering — so learn it well.
