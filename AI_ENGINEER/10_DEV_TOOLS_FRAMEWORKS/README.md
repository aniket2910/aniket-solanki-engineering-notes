# 🧩 10 · Dev Tools & Frameworks

Frameworks glue the pieces together so you're not reinventing streaming, tool-calling, retrieval, and provider-switching by hand. As a JS/TS engineer, the **Vercel AI SDK** will likely be your daily driver.

A caution: frameworks add magic and abstraction. Learn the raw API first (Chapters 00–07) so you understand what the framework is doing *for* you — then adopt one to move faster.
