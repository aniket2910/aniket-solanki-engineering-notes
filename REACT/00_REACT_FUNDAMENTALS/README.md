# ⚛️ Topic 00: React Fundamentals

The absolute bedrock questions — what React actually *is*, the vocabulary interviewers expect you to use precisely (Node vs Element vs Component), how JSX really works under the hood, and why the whole hooks model exists. Get these rock-solid first; almost every later topic (rendering, hooks, performance) leans on the mental models built here.
